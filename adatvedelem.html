BIRS – Adatvédelmi tájékoztató

BIRS – Bérfőzők Irodai Segédje · Hatályos: 2026. november 7.

Felhasználási feltételek · English summary

1. Mi a BIRS?

A BIRS bérfőzdei nyilvántartó program. A bérfőzde saját számítógépén fut, nem felhőszolgáltatás. Az adatokat a bérfőzde (a program üzemeltetője) kezeli, ő az adatkezelő. A program készítője: Dr. Barabás Péter.

2. Milyen Google-adatokhoz fér hozzá a program?

Ha az üzemeltető bekapcsolja a mentést a Google Drive-ra, a program a Google-fiókhoz kizárólag a drive.file engedéllyel kapcsolódik. Ezzel csak az általa létrehozott fájlokat éri el: a „BIRS mentések” mappát és a benne lévő mentéseket. A fiók többi fájlját, e-mailjeit, névjegyeit, naptárát nem látja.

A program a Google-adatokat kizárólag arra használja, hogy a mentéseket feltöltse, ellenőrizze, a régieket törölje, és szükség esetén visszaállítsa őket.

3. Hol tárolódnak az adatok?

  • A Google engedélye (frissítő token) a bérfőzde számítógépén, a csak rendszergazda által olvasható beállítási mappában van.
  • A mentések a bérfőzde saját Google Drive-ján vannak, AES-256 titkosítással. A titkosítás jelszavát csak az üzemeltető ismeri.
  • A program a Google-adatokat nem továbbítja a készítőnek vagy más harmadik félnek, nem használ hirdetést, követést vagy látogatottság-mérést, és nem adja el az adatokat.

4. A Google API szabályainak betartása

A BIRS a Google API-kból kapott adatok használata és más alkalmazásba továbbítása során betartja a Google API Services User Data Policy előírásait, beleértve a Limited Use követelményeket.

5. A program saját nyilvántartása

A program a bérfőzde ügyfeleinek (főzetőinek) nevét, adóazonosító jelét, lakcímét és főzéseit a jövedéki nyilvántartási kötelezettség teljesítéséhez tárolja, a bérfőzde gépén. Ha a program felhasználója hibajelentést küld, a jelentéshez csatolt napló és képernyőkép ilyen adatokat is tartalmazhat. Ezt e-mailben a bérfőzde által beállított címzett kapja meg, és csak a hiba javítására használja.

6. Az engedély visszavonása és az adatok törlése

  • Az engedély bármikor visszavonható a Google-fiókban: myaccount.google.com/permissions → BIRS → Hozzáférés megszüntetése. A programban: Beállítások → Mentések → Google Drive kapcsolat bontása.
  • A felhőbe feltöltött mentések a Google Drive-on a „BIRS mentések” mappa törlésével törölhetők.

7. Kapcsolat

Kérdés esetén a bérfőzdéhez, mint adatkezelőhöz lehet fordulni, illetve a program készítőjéhez: dr.peter.barabas@gmail.com.

English summary

BIRS is a record-keeping program for a Hungarian contract distillery. It runs on the distillery's own computer. When Google Drive backup is enabled, it uses only the drive.file scope: it can access only the files it creates (encrypted backups in a “BIRS mentések” folder) and nothing else in the account. The refresh token stays on the distillery's computer. Google user data is used only to upload, verify, prune and restore backups, and is never shared with the developer or any third party, sold, or used for advertising. BIRS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions. Contact: dr.peter.barabas@gmail.com.
